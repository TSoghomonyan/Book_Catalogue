# Book Catalogue

A small C++ application for practicing object-oriented design.

This repository is for my personal study. I'm working through
*Object-Oriented Software Design in C++* by Ronald Mak and keep
changing this project as I go through the lessons.

Feel free to use it for your own experiments as a simple application.

## Branches

- `my_solution`: books use inheritance (`Fiction`, `CookBook` and
  `HowTo` derive from `Book`).
- `Other_Solution`: the same application without inheritance. Books are
  created by factory functions and stored by value.
